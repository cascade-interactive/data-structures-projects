# Project 1

This is a group programming assignment. You can find groups under the People tab. Only one member of your group will submit. Note that the groups are self sign-up. You must be in a group to submit, even if your group only has one person in it. Each member must participate. For this first assignment, please let the lesser-experienced teammate be the driver; however, if both of you are willing, take turns being the driver.

In this project, you will create a program that implements a Circularly Linked List.

You must implement one or more classes in addition to the classes you will use to create your circularly linked list data structure. In addition, the linked list data structure must accept an arbitrary element type using templates.

Design your program around an idea of interest with your group member (be creative!). For example, you could design a program to track car sales using a singly linked list for a car dealership. Your project idea must be original.

Your submission must include:


A PDF file with the following information (try to use concise language, limited this file to no more than 3 pages):

1.All names of the group members.
2.Project name
3.Instructions on how to run your program in the student cluster.
4.Instructions on how to interact with your program, e.g., how to add or remove from the list.

5.The distribution of work completed as a percentage for each teammate, e.g., student 1's name:65%, student 2's name: 35%. It is important that each student is contributing as agreed upon between the two teammates. Students with low percentages may receive a lower score than their teammate.
6.The following statement of academic integrity:
"We understand that there will no tolerance towards academic dishonesty, and that cheating will lead to an academic referral. We are aware of the identified behaviors that are considered violations of the academic standards for Undergraduate and Graduate students per USF policy."


A folder containing ONLY the files needed to run your program.
1. All code must be clearly documented with comments, e.g., for functions, include a comment to describe what it is used for.
2. Variable names should correspond with the data they hold, e.g., int cost for a dollar amount.
3. Similarly, function names should correspond with the purpose of the function.
4. Code should be cleanly written and easy to follow using coding best practices
(https://www.educative.io/blog/coding-best-practices).

Place your folder of code and the pdf in a zipped folder named <GroupName.zip> for submission.

Submit the .zip file.
